# Android 1.26.1001 build 1524

發行日期：2026-10-01。版本碼：`29847324`。適用 Android 8.0 以上、arm64 裝置；此 APK 是操作遠端電腦的 Viewer，不提供手機被控模式。

## 功能與修正

- **縮放與拖移**：雙指開合可在 100%～800% 間縮放，雙指拖移可視區；工具列百分比選單提供放大、縮小、適合畫面及單指拖移。
- **右鍵與遠端捲動**：預設短按為左鍵、長按為右鍵；百分比選單可切換「單指捲動遠端內容」。外接滑鼠支援左／右／中鍵與垂直滾輪。
- **多螢幕切換**：頂端選單顯示 Host 回報的螢幕，切換時等候確認及新影像，再恢復遠端輸入；螢幕移除或逾時會顯示狀態。
- **遠端聲音**：點喇叭按鈕開啟，預設關閉；自動協商 Opus／AAC／PCM，支援失敗備援及背景／焦點清理。不使用手機麥克風。
- **站台與 Shell**：支援手動新增／編輯／刪除站台、加密記憶密碼、QR 掃描匯入及 Shell；QR 匯入須核對後儲存。
- **關閉按鈕定位**：開始串流時回到標題列右上角，旋轉、重連及退出全螢幕後不再累積偏移。可拖曳至安全區內其他位置，點擊即可返回站台列表。

## 安裝與升級

1. 下載 APK；若 Android 詢問安裝來源權限，允許此次使用的瀏覽器或檔案管理器安裝。
2. 在被控電腦啟動 YourDesk Host，於手機輸入遠端 ID／IP，或選擇已儲存的站台。
3. 輸入連線密碼後開始桌面或 Shell 連線。遠端聲音、多螢幕與中文輸入等能力依 Host 版本及系統權限而定。

正式套件名稱為 `com.yourdesk.android`。使用相同正式憑證的後續 APK 可直接更新並保留 App 資料。

舊 `0.1.0` 測試版使用不同的 Debug 憑證，不能直接以此 APK 覆蓋。若保有原金鑰，可依[簽章遷移說明](ANDROID-BUILD.md#發行範圍)升級；本次已在 Android 11 實測保留站台與記憶密碼。缺少原金鑰時，先保存站台資訊並確認可重新取得密碼，再評估卸載重裝；卸載會清除 App 資料與 Keystore 金鑰。
