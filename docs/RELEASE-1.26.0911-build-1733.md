# YourDesk 1.26.0911 build 1733

## 本次更新

- 新增 HTTPS 備援，WSS 無法連線時自動切換；使用同主機 8081，與管理網頁分離。
- Tailcat 模式提供另一種連線通道，預設關閉並標示實驗性。任一端開啟即可，兩端版本皆須支援；連線失敗時會提醒更新對方或關閉後重試。
- 自動配置先按「開始」偵測，完成後按「套用」才生效。以 30 FPS 上限實測，提供 5～30 FPS 建議，取消會保留原設定。
- 連線介面等首張遠端畫面準備好才隱藏；統一設定樣式、簡化泡泡說明並同步四種語言。
- 新增 WinPE x64 實驗性 ZIP 便攜包。

## 驗證與限制

本機 Go 測試、Host 驗證、雙向文字／檔案傳輸、Tailcat 封包、自動配置操作流程及 MCP 存取規則通過。Windows amd64／arm64 編譯與 WinPE ZIP 檢查通過。HTTPS 備援已在正式服務驗證。

Tailcat 與未登入連線維持實驗性；不保證所有網路皆可連線。Windows 安裝更新、WinPE 開機及原生視窗操作仍需實機驗證。WinPE 不支援 Tailcat、剪貼簿或自動更新。
