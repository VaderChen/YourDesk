# 遠端重啟後重新連線

遠端更新或重新啟動會使原本的 P2P 工作階段失效。近端必須結束舊遠端顯示程序、關閉其 signaling 連線，並由管理介面移除該站台的執行狀態，才能重新啟動連線。

一般遠端視窗現在與 MCP 隱藏模式一樣，觀察 `Peer.Done()`；P2P 確認斷線後會正常離開視窗迴圈並執行資源清理。原先一般視窗只有統計背景工作停止，視窗與程序可能繼續存在，造成近端仍認為該站台正在執行。

判斷依據為 P2P 連線狀態，不以 FPS、畫面靜止或剪貼簿活動作為斷線依據。此修正讓使用者可以重新連線，沒有新增自動重連，也沒有改動伺服器的 Host 占用規則。

驗證範圍：本機編譯檢查；尚未以兩台實機重現更新流程。因此，這項修正處理已確認的工作階段殘留缺陷，尚不能斷言所有一至兩分鐘等待情況都已解決。若仍發生，需對照雙端同一時間的連線紀錄，區分 Host 重新註冊、握手等待與 P2P 斷線偵測。
