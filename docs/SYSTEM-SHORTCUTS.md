# 系統快捷鍵作用對象

遠端桌面控制啟用時，以下快捷鍵先顯示「本機／遠端／取消」對話框，每次操作各自確認：

| 觀看端 | 快捷鍵 | 選擇本機 |
| --- | --- | --- |
| macOS | Cmd+Q | 結束本機 YourDesk |
| macOS | Cmd+W | 關閉本機遠端顯示視窗 |
| Windows | Ctrl+W、Alt+F4 | 關閉本機遠端顯示視窗 |
| Windows | Ctrl+Shift+Esc | 開啟本機工作管理員 |

選擇遠端時，只向目前連線送出一次完整按下／放開序列，沿用目前 MacOS/Windows 按鍵映射設定。例如 Mac 連 Windows 且映射啟用時，Cmd+W 仍轉為 Ctrl+W。這是鍵盤轉送，實際行為由遠端前景程式決定。

Ctrl/Cmd+C、V 等一般編輯快捷鍵不新增詢問，沿用原有剪貼簿流程。工具列的「系統快捷鍵」選單也可開啟上述選擇，不必按實體快捷鍵。點擊視窗關閉按鈕仍是明確的本機操作。

對話框預設選取遠端，按 Enter 確認遠端操作；Escape 取消。遠端不可用或安全快捷鍵無法執行時，預設選取取消。開啟前釋放遠端已按下的鍵與滑鼠、取消排隊中的輸入。等待期間不轉送鍵鼠，選擇後等待觸發鍵、修飾鍵及確認按鍵／滑鼠放開，再執行一次；不重播等待期間的輸入。遠端斷線時取消對話框，視野或連線變更後不送出原先確認的快捷鍵。

## Ctrl+Alt+Del

在工具列選擇 Ctrl+Alt+Del，再按「遠端」，會呼叫已認證 Host 的 `input.secure-attention` 命令，由 Windows 登入前服務執行 `SendSAS(FALSE)`。本機按鈕保持停用；Windows 實體 Ctrl+Alt+Del 仍由系統直接處理。

使用條件：

1. 更新兩端 APP；遠端 Windows 需重新安裝／啟用新版「未登入開機」服務，確保服務副本也是新版，再重新連線。
2. Windows 群組原則「電腦設定 → 系統管理範本 → Windows 元件 → Windows 登入選項 → 停用或啟用軟體安全注意序列」允許「服務」。對應系統原則值 `SoftwareSASGeneration` 為 `1`（服務）或 `3`（服務及輔助工具）。APP 不覆寫管理原則。
3. 一般使用者 Host、舊版 Host、非 Windows 遠端或未允許 SAS 的系統會回報原因。

服務從管線取得來源 PID，核對 SYSTEM 身分、受保護安裝路徑及目前主控台 session，再由 SCM 服務本身呼叫 `SendSAS(FALSE)`，不模擬 Host 的複製 SYSTEM 權杖。不信任請求提供的身分或 session。一般互動使用者的狀態／斷線管線權限不代表可發 SAS。

`SendSAS` 沒有回傳值，成功回覆只表示已提交，請以遠端畫面確認。新版代理保留桌面切換期間的 Host；舊服務仍可能中斷並需重新連線。2026-09-21 在 Windows 10 19045 實測，同機原則值為 1，原模擬 Host 權杖路徑沒有顯示安全桌面；獨立 SCM 診斷服務直接呼叫成功顯示安全選單。同日將修正版 build 1616 安裝至該機的登入前服務，從 macOS 顯示區域選單選擇「Ctrl+Alt+Del → 遠端」，已確認安全選單出現，且 P2P 連線保持。

參考：[Microsoft SendSAS](https://learn.microsoft.com/en-us/windows/win32/api/sas/nf-sas-sendsas)。


## 虛擬鍵盤

顯示區域的快捷鍵選單第一項為「虛擬鍵盤」，下方以分隔線區分既有快捷鍵。使用 WebView 顯示全尺寸 ANSI 配置：主鍵區、功能鍵、編輯／方向鍵及獨立數字鍵盤；Mac 配置含 F1–F19、Command、Option、Fn，Windows 配置含 F1–F12、Win、Alt、Print Screen、Scroll Lock、Pause。

新版遠端透過 `keyboard-capabilities.platform` 回報平台。舊版未回報時先使用本機配置，並可在鍵盤上手動切換 Mac／Windows。按鍵沿用掃描碼與剪貼簿輸入佇列，不將點擊轉送為遠端滑鼠事件。修飾鍵先在介面選取，點選一般鍵時送出完整按下／放開序列；送出後取消修飾鍵選取。Caps Lock 可切換，Fn 組合以 macOS 的修飾旗標傳遞。

輸入仍受目前連線、控制開關與顯示區域一致性檢查限制；關閉面板或連線中斷會解除輸入保護。Ctrl+Alt+Del 沿用登入前服務的 SAS 通道。虛擬鍵盤需遠端支援掃描碼協定；實際輸入字元由遠端鍵盤配置及輸入法決定。

驗證：`go test ./cmd/remote ./internal/hostsession ./internal/shortcut ./internal/rawkey`、`scripts/smoke-virtual-keyboard.cjs` 與既有快捷鍵 DOM smoke；實際 Mac／Windows 遠端輸入仍需連線驗證。

鍵盤頂端可拖曳；macOS 使用可移動子視窗，Windows 在顯示區域內移動並同步更新滑鼠命中範圍。選單另外提供「數字鍵盤」及標準注音配置；這兩種配置沿用最近選取的 Mac／Windows 掃描碼平台。注音符號對應實體鍵，遠端須啟用注音輸入法。底部操作說明已移除，視窗高度隨鍵盤內容調整。

虛擬鍵盤為非模態浮層：開啟後仍可在遠端畫面移動、點擊、拖曳及捲動滑鼠；鍵盤浮層內攔截滑鼠，避免穿透。切回遠端畫面不會自動關閉鍵盤。實體鍵盤仍暫停轉送，確認對話框則維持完整輸入阻擋。

macOS 鍵盤命中檢查使用主執行緒發布的位置快照，不從畫面更新流程同步等待 AppKit；鍵盤未開啟時不執行命中檢查，避免影響初始畫面更新。回歸測試涵蓋未啟動 AppKit 事件迴圈時仍能立即返回。

SAS 回報會直接顯示在目前顯示區域的快捷鍵泡泡，或開啟中的虛擬鍵盤內。選單與虛擬鍵盤使用同一條指令，重複點擊不會同時發出多筆 SAS；指令錯誤不再被視為整個連線失敗。一般 Windows Host 也會回報需要啟用服務的明確原因。

更新 App 不等於更新已安裝的登入前服務副本；若服務仍是舊版，需在遠端停用再啟用「未登入開機服務」，然後重新連線。另須在遠端「電腦設定 → 系統管理範本 → Windows 元件 → Windows 登入選項 → 停用或啟用軟體安全注意序列」啟用並選擇「服務」。遠端指令不會修改系統管理原則；只有遠端電腦的本機使用者確認並通過 UAC 後，才可新增服務產生 SAS 的權限。以上條件若未滿足，僅更新雙方 App 仍無法送出 SAS。


Windows App 開啟時會檢查服務與 SAS 權限；未就緒時先顯示 WebView 授權說明，使用者按「授權」才啟動 UAC。已安裝服務時只調整 SAS 原則；尚未安裝時，說明中會明示啟用登入前服務及開機自動啟動。已授權不重複詢問，取消後本次開啟不再自動詢問；設定頁的「授權 Ctrl+Alt+Del」可手動重試。macOS／WinPE 不顯示此要求。

提升權限的輔助程序只新增 `SoftwareSASGeneration` 的服務位元，保留既有輔助使用權限；不明原則值拒絕覆寫，UAC 取消或系統管理原則未允許時顯示失敗。授權結果重新讀取系統原則，不以本機偏好值代替。此流程不會自動替換已安裝服務的程式副本；舊版服務仍需停用再啟用更新。

### 安全桌面切換與串流

Windows 登入前代理不再因 Default／Winlogon 桌面切換而停止整個 Host。
擷取工作執行緒在取得每張影格前確認目前桌面；切換時先釋放 DXGI／GDI 資源，
再綁定新桌面並重新擷取，保留原有 P2P 工作階段。輸入沿用獨立執行緒的桌面切換機制。
一般權限程序若無法存取安全桌面，會暫停擷取並等待恢復，不把舊桌面當成新影格送出。

「Ctrl+Alt+Del 已交給遠端 Windows 服務」僅表示 SAS 呼叫已提交；Windows SendSAS
沒有成功回傳值，仍需以遠端實際顯示安全桌面確認。更新此修正後，既有 Windows
登入前服務也需停用再啟用以更新受保護的服務副本，操作期間會中斷遠端連線。
