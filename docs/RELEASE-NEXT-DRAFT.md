## 設定與系統快捷鍵

- 統一設定頁的「實驗性功能」標籤樣式，包含斷線後自動重連與英、日、韓翻譯。
- 遠端控制期間，Cmd+Q/W、Ctrl+W、Alt+F4 與 Windows Ctrl+Shift+Esc 先選擇本機／遠端／取消；Ctrl/Cmd+C/V 維持原有行為。工具列提供系統快捷鍵入口。
- Ctrl+Alt+Del 由 Windows 系統優先處理，目前不支援遠端合成；介面明確提示限制。詳見 [系統快捷鍵作用對象與驗證範圍](SYSTEM-SHORTCUTS.md)。
