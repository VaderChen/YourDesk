# 桌面檔案傳輸

站台卡片的操作順序為：刪除、編輯、CMD、檔案傳輸、GUI。檔案傳輸使用獨立視窗與配對密碼，不啟動命令列、遠端顯示或剪貼簿同步。兩端均須支援獨立檔案工作階段協商及 `xfer.*`；舊版或服務身分不支援時會明確回報，不退回桌面串流。

本文件描述原始碼實作與驗證範圍，不代表既有 Release 安裝包已包含此功能；套件支援情況請核對對應發行說明。

## 操作

1. 關閉該站台目前的 CMD／GUI 連線，按檔案傳輸圖示並完成認證。同一站台目前仍使用單一遠端工作階段。
2. Windows 遠端從 `C:\` 開始；Mac／Linux 從 `~/` 開始，路徑列顯示目前實際位置。清單最上方「..」可返回上一層，離開家目錄並瀏覽遠端使用者有權限存取的磁碟／資料夾。按「磁碟」可直接選擇遠端磁碟；Windows 磁碟根目錄及 Mac 的 `/` 可再返回磁碟清單。Linux 在 `/` 停止。從 Finder／檔案總管將本機檔案或資料夾拖入右側上傳區，或使用「選擇本機檔案」。目的地是當時顯示的遠端資料夾。
3. 下載時，選擇遠端一般檔案並按「下載所選檔案」。在 APP 內選擇本機資料夾，按「下載至此資料夾」後直接儲存；Windows 初始位置為 `C:\`，macOS 為 `~/`，可瀏覽上層或輸入其他路徑。取消選目錄不會開始下載。
4. 「新增資料夾」會在目前遠端位置建立一個新目錄。可勾選、Cmd／Ctrl 加選、Shift 範圍選取，或全選目前已載入的清單。單擊名稱改為單選；雙擊目錄或只選一個目錄再按「開啟資料夾」進入。刪除須先確認，可批次刪除已選項目；包含目錄時還須按列出的順序逐行輸入目錄名稱；這是永久刪除，不會移至資源回收筒。
5. 傳輸中可暫停、繼續或取消。畫面顯示百分比、已傳／總位元組、速度與預估剩餘時間；暫停時不持續計算傳輸速度。
6. 斷線時保留此視窗，回主視窗重新連接同一站台的檔案傳輸。認證成功後會重用原視窗，按「續傳」才會繼續，不自動重試檔案或刪除操作；已明確要求取消的傳輸則可在重連後完成取消。
7. 取消回覆未確認時，可再次按「取消」，其他符合額度限制的待傳項目仍可繼續。按關閉、快捷鍵或系統關窗鈕時，會先取消未完成傳輸；最多等待 8 秒。若仍未確認清理成功，保留視窗與續傳憑證並提示重試，請重新連線後再取消／關窗。

遠端清單先列資料夾，再列一般檔案，各組按名稱排序（忽略大小寫，同名以原始名稱決定順序）。分頁前完成排序與隱藏過濾；點開頭名稱、Windows 隱藏屬性及 macOS `UF_HIDDEN` 項目不顯示。清單圖示採隨 APP 打包的 Font Awesome Free：資料夾為金色，文件為藍色，離線可用。舊 Host 可由接收端排序已載入的項目並隱藏點開頭名稱；完整分頁排序及系統隱藏屬性需遠端一併更新。

Mac 磁碟清單直接讀取系統掛載表，列出 `/` 與掛載於 `/Volumes` 下可瀏覽的磁碟，不受 `/Volumes` 本身的隱藏屬性影響。重新整理會更新插入／拔除狀態；磁碟名稱與通訊識別碼分離，可顯示空格、中文與冒號。磁碟根目錄不可刪除，系統標記不可瀏覽的掛載點及點開頭磁碟不列出；一般隱藏檔過濾維持不變。此功能需要控制端與遠端 Mac 一併更新。

「選擇本機檔案」直接點擊原生多選控制項；macOS 透過綁定檔案視窗的 NSOpenPanel Sheet 顯示 Finder 選檔介面，Windows 使用 WebView2 的檔案總管選檔介面。取消選檔不加入上傳佇列。

底部的「下載」標題及操作／重連說明已移除。下載進度與暫停／續傳／取消放在遠端清單下方，閒置時隱藏。

下載直接保存為所選資料夾內的原檔名，不再建立 `YourDesk/transfer-*` 子目錄，也不需要拖出；已完成檔案關窗後仍保留。取消未完成下載會清除本次暫存，暫停／斷線則保留以便續傳。

續傳僅支援雙端程式仍在執行、傳輸視窗仍開啟的情境，不保存跨關閉程式／重新開機的待傳佇列。上傳依遠端已確認的位置續傳；下載依本機已寫入的位置續傳，並重新檢查遠端檔案大小與修改時間。若來源改變、暫存過期或目的地已被占用，會停止並回報，不能把兩個不同版本接在一起。

下載遇到斷線、逾時或暫時忙碌時保留已下載部分，等待手動續傳；檔案不存在、權限拒絕或來源版本改變等明確失敗則結束該下載、顯示錯誤並清理本次暫存，不反覆要求無效續傳。

## 本階段範圍

- macOS／Windows 桌面功能；不包含 Android／iOS。
- 上傳支援檔案與資料夾，包括空目錄；每批最多 64 個項目、總計 2 GiB、16 層目錄。一次只傳一個檔案，可暫停、續傳或取消。
- 可複選一般檔案，每批最多 64 個、合計 2 GiB，選一次本機目的目錄後依序下載；不提供遠端資料夾下載。可暫停及斷線重連後續傳，取消會停止目前檔案與尚未開始的項目，已完成的檔案保留。
- 本機下載與上傳共用各平台不覆寫的提交方式；macOS／Windows／Linux 使用安全更名，不再要求硬連結。暫存檔被外部替換時仍會拒絕提交。
- 不覆寫同名檔案或合併既有目錄。檔案失敗不代表整批回滾，已完成的檔案／新目錄會保留；請依佇列結果確認。
- 傳送檔案內容與資料夾結構，不保留來源權限、可執行位元或修改時間。
- 遠端存取以目前互動使用者的系統權限為準，不提權、不跟隨符號連結或特殊裝置；不提供改名。不能修改磁碟根目錄、虛擬磁碟清單、上傳暫存或正在上傳的目的地／其上層目錄。
- 遞迴刪除會先檢查目錄內容，最多 4,096 個項目、32 層；含不支援的項目或超出限制時不開始。刪除不是交易：若途中斷線、內容被其他程式更動或權限不足，已刪除項目不會復原。收到部分失敗回覆時顯示已刪除數量；若連回覆也遺失，請重新整理確認現況，不自動重試。
- 目錄結果分頁、畫面最多顯示 1,000 筆。為控制全目錄排序的記憶體與耗時，單一目錄列舉上限 100,016 個項目（含隱藏項目），超出會回報錯誤而不回傳未完整排序的清單。傳輸目前使用受限指令通道的 4 KiB 區塊，優先保留既有訊息大小與背壓界線；尚不是針對高延遲網路最佳化的高速大檔管線。

## 實作邊界

- `internal/p2p`／`internal/hostsession`：Host 在已簽章的 offer 宣告檔案模式版本，Viewer 在已簽章的 answer 選擇 `sessionMode: files`。Host 在建立桌面擷取、編碼器、剪貼簿服務或要求桌面輸入權限之前分流；此模式不註冊 Shell、桌面或輸入指令，P2P 也拒絕畫面及剪貼簿內容傳送。未帶模式的既有桌面／終端機協定維持相容。
- `internal/filetransfer`：每次操作重新檢查身分／授權；網路路徑採磁碟識別碼加相對路徑，只可從 Host 列舉的磁碟根目錄逐層開啟，保留 `os.Root` 與檔案身分檢查；檔案完成才原子提交，禁止覆寫。同一 Host 程序共用受限暫存表，全程序最多 4 個上傳、合計 2 GiB 預留量，並依使用者家目錄身分及路徑範圍隔離認領。Host 執行期間定期清理閒置達 24 小時的未完成暫存。Peer 結束只解除擁有權；新 Peer 須重新認證，並提供正確續傳 token、路徑及大小才能認領，不能搶走另一個仍在線 Peer 的工作。
- Host 程序結束後無法續傳，尚未取消的 `.yourdesk-transfer-*.part` 可能殘留於原上傳目錄；重新啟動不會掃描家目錄或猜測檔案擁有權並刪除。清理前須先確認沒有進行中的傳輸。一般暫停／斷線請保留兩端程式，取消則透過傳輸佇列完成。
- 上傳開始前產生隨機續傳 token，讓 `begin` 回覆遺失仍能認領；尚未收到開始回覆時，可用原 token 冪等確認，已確認開始後則由 `resume` 回覆已寫入 offset，避免重送已確認區塊。完成記錄最多 64 筆、保留最多 24 小時，供提交成功但回覆遺失時確認結果；不把 token 寫入磁碟佇列。
- 取消以完整的識別碼、token、路徑與大小獨立驗證，不要求目的地或暫存仍能續傳。因此目的地衝突、目錄搬移或暫存變動後仍可取消並釋放額度；不刪除外部替換的檔案或已完成檔案。完成記錄存在時，重複取消回覆 `complete`；記錄過期或淘汰後，`cancelled` 僅表示沒有保留中的待取消作業，不能據此推定檔案從未提交。
- `internal/clientui/files.go`：HTTP token、Origin 與工作階段 instance 驗證；舊 instance 不能操作新連線。只有主視窗重新認證同站台、同配對目標後，才能經子程序控制通道更新既有傳輸視窗。遠端檔案指令不能切換成 Shell 或桌面操作。
- `internal/clientui/files_window.go`：原生視窗使用獨立子程序。下載在背景執行；UI 回呼只排程、暫停、繼續或取消工作，不等待磁碟或網路傳輸。頁面準備完成後，系統關窗要求轉送至同一個非阻塞清理流程；頁面載入失敗或父程序結束仍可終止視窗。續傳仍須明確操作，不因視窗收到新工作階段而自動開始。
- `internal/clientui/files_destination.go`：WebView 的本機資料夾選擇介面，每次最多讀取 256 個目錄項目，磁碟列舉於背景執行；本機路徑不傳送遠端。檔案視窗不再安裝底部原生拖出區。

## 驗證與平台驗收

### 已完成驗證（2026-09-21）

- 全專案 `go test ./...` 通過；檔案傳輸、Client UI、Host 工作階段、P2P、signaling 及 Remote 相關 race 測試連續三輪通過，相關 `go vet` 通過。
- 45 項 JavaScript 回歸與 Edge 四語系 smoke 通過，涵蓋暫停／續傳、回覆遺失、重連舊回覆、取消失敗後繼續佇列及限時關窗清理。
- 真 TLS／已簽章 signaling／loopback Pion 檔案模式測試連續十輪 race 通過，涵蓋一般及 headless Host、舊 Viewer 相容與舊 Host 明確拒絕檔案模式。
- macOS 原生 Client 視窗測試與 Cocoa 關窗攔截測試各三輪通過；涵蓋頁面準備完成、下載暫停／重綁／手動續傳／取消、父管線 EOF 強制回收，以及恢復原生關窗回呼。
- Windows 的 Go 邏輯測試交叉編譯通過；不含 Windows CGo 原生視窗、關窗及拖放的執行驗證。Finder／Explorer 實際拖入拖出與跨機傳輸仍須依下列清單驗收。

### 重跑入口

本機測試入口：

```sh
go test -race ./internal/filetransfer
go test -race ./internal/clientui -run 'Test(File|Files|Download)'
go test -race ./internal/p2p -run TestFilesSession
go test -race ./internal/hostsession -run TestFiles
node scripts/test_files_ui.js
node scripts/smoke-files-ui.cjs
```

瀏覽器 smoke 需安裝 Playwright 與 Chromium；若使用 Edge 可設 `FILES_BROWSER_CHANNEL=msedge`。測試只連隔離 mock，不進行真實遠端刪除。原生視窗測試則須以 `YOURDESK_FILES_WINDOW_BINARY` 指定已建置的 Client，執行 `TestNativeFilesWindows`；測試在初始 metadata 階段模擬暫停／重綁／續傳，不寫入使用者目錄。

`TestFilesSession` 使用暫存 CA、真 TLS／簽章 signaling 與 loopback Pion，驗證檔案模式分流及新舊端相容性，不連外部站台。另可設 `YOURDESK_NATIVE_CLOSE_TESTS=1` 執行 `TestNativeFilesCloseHook`，以本機 C 編譯器與隔離隱藏視窗驗證系統關窗攔截、原生回呼還原與直接終止。

本機檔案橋接與拖入必須另以各平台實機驗收，瀏覽器模擬不能代替：

- Finder／Explorer 拖入單檔、多檔、含空目錄的資料夾。
- 下載前選擇本機可寫目錄，驗證內容直接寫入所選位置、取消選目錄不開始下載、剪貼簿未變。
- 拖曳取消、下載取消、斷線、關窗、磁碟滿、同名衝突、零位元、長中文檔名及 2 GiB 邊界。
- 上傳／下載途中暫停再繼續；寫入回覆遺失、提交回覆遺失、斷線重連後續傳，驗證完整內容與 offset，不只看進度條。
- 下載暫停後更動遠端來源、上傳暫存過期、切換站台或配對目標，確認拒絕錯接內容。
- 在專用測試目錄驗證建立、刪除單檔、非空目錄、取消確認、名稱不符、符號連結、正在傳輸的路徑及部分失敗；不要用真實資料進行破壞性測試。
- 關閉傳檔視窗後，確認遠端工作階段結束且已完成下載仍保留。
- 取消回覆遺失後重試、目的地衝突後取消、傳輸途中按系統關窗鈕，確認額度釋放且不丟失未確認工作的憑證。
- 只建立檔案連線時，Host 不出現畫面擷取／輸入權限要求，不建立影像編碼器；桌面、Shell、剪貼簿操作不可用。

Windows 原生橋接需要 Windows CGo 工具鏈及 Explorer 驗證；`CGO_ENABLED=0` 交叉編譯只涵蓋 Go 邏輯，不能視為原生拖放驗收。

## 直接選擇下載目錄

2026-09-22 以隔離目錄及瀏覽器 Smoke 驗證「..」導覽、取消選目錄不下載、指定目的目錄、同名保護、暫停／續傳及關窗清理。macOS 原生 WebView 的目錄列舉與下載控制橋接 Smoke 通過；macOS arm64、Windows amd64 Client 含 CGo 建置通過。跨機及 Windows 實際檔案系統操作仍需實測。

新版 Host 的 `xfer.location` 提供預設位置，`xfer.list` 提供顯示路徑及上一層。舊 Host 未提供時沿用舊版家目錄範圍；需更新遠端才能離開家目錄。磁碟存取與既有上傳共用有界佇列、無覆寫提交及續傳檢查。

本輪補驗證磁碟間上傳／讀取、家目錄返回上層、根目錄保護、符號連結拒絕、不同帳號／舊路徑範圍不可認領續傳；瀏覽器 Smoke 涵蓋 Windows `C:\` 起點、切換 D 磁碟、Mac `~/ → /Users → /` 及底部下載區塊移除。跨機 Windows 實際檔案系統仍待實測。

2026-09-22 清單與複選驗證：51 項 JavaScript 回歸、四語系瀏覽器 Smoke 及淺／深色畫面檢查通過，涵蓋資料夾優先、跨頁排序、隱藏項目、Font Awesome 載入、原生選檔事件與複選、批次下載的失敗／取消／檔案交界暫停，以及批次刪除遇未確認結果即停止。Go 檔案傳輸測試與清單 race 測試通過，macOS 實際 `UF_HIDDEN` 檔案／目錄過濾、原生選檔 Sheet 開啟／取消／重開／清理及既有檔案視窗橋接 Smoke 通過。Mac arm64 與 Windows amd64 Client 建置通過；Windows 原生選檔與隱藏屬性仍待 Windows 實機驗證。

檔案傳輸視窗頁面就緒時會移至前景；再次開啟同一工作階段會喚起原視窗，不重新載入頁面，也不清除傳輸佇列。
