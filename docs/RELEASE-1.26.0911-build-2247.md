# YourDesk 1.26.0911 build 2247

本版改善介面操作，保留遠端桌面、命令列與 MCP 功能。

- 記住上次選擇的站台群組，重新開啟自動恢復；群組不存在時回到所有站台。
- 對話框開啟時聚焦操作欄位，避免標題自動出現焦點框。
- 本機狀態文字改為「一切就緒／無法連線」。
- MCP 服務位址的標籤、網址與複製圖示垂直置中。
- 關於頁顯示完整 GitHub 網址，並加入 [Buy Me a Coffee](https://buymeacoffee.com/vaderchen) 支持開發連結。
- 相關介面文字同步繁中、英文、日文與韓文。

套件包含 macOS Apple Silicon DMG、Windows x64／ARM64 安裝程式、WinPE x64 實驗性 ZIP，以及 Linux x64／arm64 CLI ZIP。Linux 目前提供命令列被連線端，不包含圖形處理與 REMOTE。

## English

Remembers the last selected site group, places dialog focus on an actionable field, updates the local status labels to Ready / Unable to connect, and vertically aligns the MCP address row. About now shows the full GitHub URL and a Buy Me a Coffee support link. Related labels are translated into four languages. Includes macOS, Windows, experimental WinPE and Linux CLI packages; Linux remains a terminal-only Host.
