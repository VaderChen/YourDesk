# YourDesk

Windows 裝置 ID 已改用 MachineGuid，無效時以 SMBIOS UUID 備援，不再使用 CPU 特徵值；更新影響見 [Windows 裝置 ID](WINDOWS-DEVICE-ID.md)。

**繁體中文** · [English](docs/README.en.md) · [日本語](docs/README.ja.md) · [한국어](docs/README.ko.md)

YourDesk 是以 Go 開發的 P2P 遠端桌面，提供內嵌 HTML／JavaScript／CSS 的原生管理介面、常駐 Tray 的 Client，以及獨立 遠端顯示。桌面影像與鍵鼠控制透過 WebRTC DTLS 加密直傳，不使用 TURN 中繼。

![YourDesk 介面預覽](images/cap001.png)

## 下載與啟動

從 [GitHub Releases](https://github.com/VaderChen/YourDesk/releases/latest) 下載對應平台套件。Release 名稱與 App 顯示版本一致：`1.YY.MMDD build HHmm`；標籤以 `1.YY.MMDD-build-HHmm` 表示同一版號。

| 平台 | 套件 | 啟動方式 |
| --- | --- | --- |
| macOS Apple Silicon（arm64） | Developer ID 簽章與 Apple 公證的 DMG／App | 開啟 YourDesk.app |
| Windows x64（amd64）／ARM64 | ZIP，依 Release 實際提供的架構下載 | 完整解壓縮後執行 YourDesk.exe |

macOS Intel 不支援，Linux 暫不提供桌面套件。Windows 需要 Microsoft Edge WebView2 Runtime；不要把 YourDesk.exe 與同目錄的輔助執行檔分開。Windows 套件內附四種語言的 README。

## 連線與站台

- 開啟 YourDesk 後，本機 Client 自動執行。關閉管理視窗仍常駐 Tray；從 Tray 選單選擇「關閉程式」才會完整結束。
- 使用快速連線貼上遠端 ID，或新增站台後雙擊項目連線。需要密碼時顯示輸入視窗，支援「記住我」。
- 送出連線後會顯示「正在建立連線」動畫，可取消；遠端顯示 繪出第一張畫面後關閉動畫，失敗時顯示錯誤。
- IP 離線直連支援 IPv4、IPv6、`IP:port` 與 `[IPv6]:port`，不需要中央 Server。入口預設關閉；被控端須在「網路安全」啟用後，才會監聽 TCP 47823。網路仍須允許 WebRTC UDP 流量。
- 站台與群組可拖曳排序；左側「＋」新增群組，群組右鍵可改名／刪除。設定中可匯入／匯出站台檔。
- 綠色站台圖示代表 Server 回報 Client 已註冊，不保證握手或 P2P 網路一定能完成連線。

## 遠端顯示 工具列、縮放與螢幕

macOS 使用內嵌 WebView 標題列，從左至右提供標題、`編碼狀態 │ FPS │ TX RX │ 畫質／縮放／螢幕`。畫質按鈕使用圖片圖示，操作按鈕搭配泡泡提示與原生 Popup 選單。中央展開最多四個帶編號的螢幕按鈕，左右各有分隔線，目前螢幕使用綠色外框。Windows 目前保留原生標題列與畫布工具列，尚未提供同樣的 WebView 畫質選單與統計列。

縮放只影響本機顯示，不改變遠端串流尺寸：

- **自動符合視窗**：新連線預設，保持比例縮放至可用區域；已有保存設定時沿用原選擇。
- **原始解析度（1:1）**：以來源像素大小顯示。
- **只縮小，不放大**：較大的來源縮小，較小的來源不放大。

macOS 多螢幕由中央按鈕直接選擇，Windows 原生工具列按鈕依序切換。畫面與滑鼠座標同步切換；等待目標螢幕完整影格期間暫停遠端輸入。只有一個螢幕時不進行切換。Client 與 遠端顯示 都需更新；舊版仍可連線，但無法使用完整的新功能。

FPS 每秒更新，統計實際繪製的新遠端畫面，不把同一張畫面的重畫計入。TX／RX 為此連線的傳送／接收速率，依大小顯示 KB/s 或 MB/s。實際 FPS 受擷取、編解碼、網路及畫面變化影響，不等於設定的目標 FPS。

### 視窗式全螢幕

macOS 的全螢幕採無邊框視窗填滿目前螢幕，保留同一個視窗與繪圖表面；不進入 macOS 原生全螢幕、不切換 Space。退出時還原進入前的大小與位置；若原螢幕已移除，會把視窗放回可用螢幕。

可從縮放選單、綠色按鈕或雙擊標題區切換。一般視窗可拖曳標題文字與中央空白區移動。全螢幕工具列預設隱藏，滑鼠停在頂端約 6pt 範圍滿 **1 秒**後浮現；離開工具列約 0.25 秒後收起，選單開啟期間保持顯示。工具列覆蓋在畫面上，不擠壓畫面，也不因顯示／隱藏而改變串流尺寸。

## 畫質與 FPS

macOS 遠端顯示 在縮放左側提供畫質選單，未保存設定時預設為「標準」。兩端都更新後即可切換：

| 模式 | 遠端串流尺寸 | 壓縮品質與目標 FPS |
| --- | --- | --- |
| 低流量 | 寬、高最多各為原畫面一半，再依 遠端顯示 可用實體像素等比例縮小 | JPEG 品質最高 50；目標 FPS 比基準提高 50%，向上取整，最高提升至 30 FPS；基準已達 30 FPS 以上時保留原值 |
| 標準 | 保留來源尺寸 | 使用啟動時設定的壓縮品質與 FPS |
| 高畫質 | 保留來源尺寸 | 壓縮品質至少 95，原設定較高時保留；FPS 恢復基準值 |

以下為未套用明確串流參數時的舊畫質策略；新版設定的來源 FPS 上限預設 20，優先於策略倍率。低流量模式的硬體編碼平均碼率依縮圖尺寸與**基準 FPS**計算：每像素每基準影格 0.125 bit，限制在 256 Kbps～4 Mbps；增加 FPS 不提高碼率預算。這是平均碼率目標，並非每秒傳輸量的硬性上限。硬體碼率設定失敗時退回 JPEG。

macOS 低流量縮圖優先使用 Metal／Core Image GPU；初始化或運算失敗時使用 CPU，30 秒後重試 GPU。Windows 優先使用 D3D11 Video Processor 縮圖，失敗時使用 CPU，30 秒後重試。遠端顯示 尺寸穩定後才通知遠端更新；視窗變大但仍受半解析度上限限制時，不因視窗尺寸改變而重建編碼器。

### 編碼與解碼

硬體編碼不代表 遠端顯示 一定使用硬體解碼。自動協商會考慮兩端能力；影片編碼優先 HEVC，再 H.264，無法使用時退回 JPEG。JPEG 路徑依平台能力與設定嘗試硬體編碼，否則使用軟體。

| 遠端顯示 平台／格式 | 目前解碼方式 |
| --- | --- |
| macOS H.264／HEVC | VideoToolbox 自動選擇硬體或軟體；有實際解碼能力探測，並回報當次是否使用硬體 |
| macOS JPEG | Go 軟體 JPEG 解碼；硬體 JPEG 解碼尚未實作 |
| Windows H.264 | Media Foundation／D3D11 硬體解碼，探測或運行失敗時協商退回 JPEG |
| Windows JPEG | Go 軟體 JPEG 解碼 |

高畫質模式會提高傳入編碼器的品質參數，實際效果取決於所選編碼器；不代表所有硬體都接受相同的品質控制方式。

## 滑鼠、鍵盤與剪貼簿

macOS 被控端依系統雙擊時間與游標位置累積連點次數，按下／放開事件帶有一致的 `clickState`；移動超過容許距離或切換按鍵時重新計算。按住滑鼠移動時注入對應的拖曳事件。

新版 Client／遠端顯示 協商原始鍵盤模式。遠端顯示 在本機輸入法處理前擷取實體按下／放開事件，傳送來源平台掃描碼、修飾鍵旗標與按鍵重複資訊，不傳送 遠端顯示 輸入法產生的組字文字。

同平台使用原始碼注入；跨平台按實體鍵位置映射。左右 Shift／Ctrl／Alt／Meta 分開處理；預設啟用 MacOS/Windows 按鍵映射：Mac → Windows 將左右 Command 映射至同側 Ctrl，Windows → Mac 將左右 Ctrl 映射至同側 Command；關閉後維持實體鍵對應；輸入結果由遠端鍵盤配置與輸入法決定。

- Caps Lock 使用完整按鍵事件與鎖定狀態快照，macOS 被控端同步 HID 鎖定狀態。
- 數字鍵盤保留獨立掃描碼；macOS 注入時保留 NumericPad 標記。
- Windows 遠端顯示 傳送 Num Lock 狀態與 E0 掃描碼。macOS Clear 保留原生行為，傳至 Windows 時對應 Num Lock；Windows Num Lock 傳至 macOS 時透過 HID 狀態介面處理。
- 失焦、切換螢幕與中斷連線時釋放按鍵。原始模式下 F12、Ctrl／Cmd + Shift + F 也送往遠端，請用工具列控制全螢幕。
- 舊版鍵盤協定下，F12 切換遠端控制，Ctrl／Cmd + Shift + F 切換本機全螢幕；恢復已保存的暫停控制狀態時仍可用 F12 啟用。
- 系統先行攔截的安全組合鍵（如 Ctrl+Alt+Delete）與無對應的平台專用鍵不能保證轉送。

剪貼簿支援 macOS／Windows 間雙向同步新複製的**純文字、圖片、檔案與目錄**，使用獨立、有序且可靠的 `clipboard` DataChannel；鍵盤滑鼠仍走 `control`。雙方支援時優先使用新通道；對方是舊版時保留原 `control` 通道作為**純文字備援（32 KiB）**。圖片、檔案與目錄只使用新通道，雙方都需更新；不將圖檔附帶的文字或路徑誤當文字傳送。

| 類型 | 支援與限制 |
| --- | --- |
| 純文字 | UTF-8，包含中文、多行與空字串，每筆最高 1 MiB |
| 圖片 | 使用 PNG 傳輸，最高 32 MiB／約 3,355 萬像素；Mac 可讀取 PNG／TIFF，Windows 可讀取 PNG／常見 24／32 位元 DIB |
| 檔案 | 每批最多 64 個一般檔案，合計 2 GiB；先提供清單，貼入 Finder／檔案總管時按需讀取快照 |
| 目錄 | 最多 64 個最外層項目，可混合檔案與目錄；保留子目錄與空目錄，合計最多 4096 筆項目、64 層、2 GiB（含封存資訊） |

檔案與目錄採「複製 → 建立本機不可變快照 → 公布清單 → 貼上時讀取內容」。建立快照及列出右鍵選單不會主動傳送整份檔案。遠端顯示 的 Ctrl／Cmd+V 等待清單公布完成後送出按鍵；Windows 右鍵貼上使用 OLE `FileGroupDescriptorW`／`FileContents`／`IStream` 與非同步資料物件，macOS Finder 使用系統內建的唯讀 WebDAV 掛載，無需另裝驅動程式。WebDAV 僅監聽隨機的 127.0.0.1 連接埠，使用隨機路徑；HEAD／PROPFIND 只提供中繼資料，GET 才讀取內容。系統或第三方程式若主動預覽檔案並要求內容，也視為讀取需求，不能將這類系統讀取誤當作只有使用者按下貼上才可能發生。

每個讀取要求最多預讀 256 KiB，透過獨立 clipboard 通道分成 16 KiB 小片段回覆，並限制並行讀取數與待送緩衝。檔案取消每片固定等待 8 ms 的節流；沒有畫面積壓時使用 256 KiB 待送緩衝，有積壓時縮為 64 KiB，鍵鼠仍優先。這是緩衝上限而非固定傳輸速度，實際速度仍受網路延遲、頻寬及磁碟影響。接收端只指定快照 ID、項目索引與位移；來源端不接受遠端傳入本機檔案路徑。內容來自已完成的本機快照，來源檔案之後變動不影響快照。貼上開始後再複製其他內容，不取消已取得舊快照的檔案讀取。純文字與圖片維持原本同步流程；舊 control 通道仍僅提供文字備援。檔案／目錄的按需讀取需兩端皆更新，不退回自動傳送整包檔案。

單一快照最高 2 GiB（含封存資訊），最多保留 8 份快照；定期及建立下一份時回收已被取代、閒置超過十分鐘的舊快照與清單，連線結束則清理本機快照與 Finder 掛載。Windows 虛擬項目的相對路徑需短於 260 個 UTF-16 字元；符號連結、特殊檔案、虛擬附件及不相容路徑仍不支援。建立快照期間來源被修改或剪貼簿被換掉，會記錄錯誤，不公布不完整項目。檔案由作業系統直接貼到使用者選定的位置，不再先完整下載到 Downloads。

不顯示 YourDesk 傳輸進度對話框。檔案貼上由作業系統處理；失焦只取消未送出的鍵盤事件，不取消系統已開始的快照讀取。單次網路讀取等待最多 45 秒；斷線或快照失效時回報讀取錯誤，不以空檔案偽裝成功。三個通道仍共用底層連線與實體網路頻寬。


## 語言與設定保存

主畫面支援 AUTO、繁體中文、英文、日文、韓文、明亮／暗調風格，以及可關閉的泡泡提示。macOS 遠端顯示 工具列、提示與選單沿用主畫面的語言，已開啟的 遠端顯示 會在背景同步變更。

設定位於作業系統的使用者設定目錄下 `YourDesk/`：macOS 為 `~/Library/Application Support/YourDesk/`，Windows 通常為 `%AppData%\YourDesk\`。

| 檔案 | 保存內容 |
| --- | --- |
| `preferences.json` | 主畫面語言、主題、泡泡提示、IP 直連開關與編碼方式 |
| `sites.json` | 站台與群組；不包含連線密碼 |
| `viewers/<識別雜湊>.json` | 按訊號伺服器與遠端分開保存畫質、縮放、螢幕編號、全螢幕、一般視窗大小與遠端控制開關 |
| `updates.json` | 上次更新檢查時間、已提醒版本與下載狀態 |

遠端顯示 設定在背景寫入，結束時等待最後一次保存；遠端螢幕減少時使用目前有效螢幕。工具列自動隱藏的顯示狀態、即時 FPS 與流量不屬於使用者偏好。

## 自動檢查與下載更新

Client 常駐期間每 **12 小時**檢查 GitHub 最新正式 Release，關閉主視窗後仍會執行。首次使用、上次檢查已超過 12 小時或本機時間異常時會檢查；重啟不重置週期。程式完全退出後不會在背景檢查。

發現新版會喚回主視窗並顯示提醒；同一版本自動提醒一次。使用者可選「稍後」，或從「關於」手動檢查與下載。只有可比較且高於目前版本的正式 Release 才視為新版。

按「下載並自動更新」後，依系統與架構下載 DMG 或 Windows Installer，保留進度、下載路徑及既有大小／SHA-256 驗證。準備成功後，由獨立更新程序回報就緒，APP 才關閉其管理中的 Host、遠端顯示及主介面；更新程序等待退出後安裝並重新啟動。不是背景檢查到新版就立即安裝。

macOS 先將 DMG 唯讀掛載，核對 APP 識別及完整簽章，複製到安裝位置旁的暫存目錄；退出後保留舊 APP，再替換整個 bundle，避免覆寫正在執行的二進位。替換或啟動命令失敗時嘗試復原。從開發啟動器、DMG 或 App Translocation 執行時，安裝至 `/Applications/YourDesk.app`；沒有寫入權限時保留 APP 並提示手動安裝，不繞過系統權限。

Windows 由獨立 PowerShell 更新程序等待 APP 退出及三個執行檔解除占用，保留原檔後以 NSIS `/S /D=安裝目錄` 安裝，再啟動 `YourDesk.exe`。開發更新測試使用每位使用者的標準安裝目錄。其他程序持續占用時停止更新，不強制終止；安裝失敗時嘗試還原原檔並保留記錄。舊 ZIP 不支援自動安裝，需手動處理。更新程序的啟動就緒等待為 15 秒，APP 退出等待為 120 秒。失敗記錄保留在 macOS 安裝目錄旁的 `.YourDesk-update-*`，或 Windows 暫存目錄的 `YourDesk-update-*` 中。

編譯與腳本語法檢查不等於完整更新驗證；仍需在 macOS 與 Windows 實機確認從正式安裝位置更新、占用失敗及重新啟動。

## 密碼、權限與加密

新安裝產生 16 字元、80 位元熵的隨機連線密碼，並提醒至設定修改。站台檔不含密碼，「記住我」資料另存於本機；啟動 遠端顯示 子程序時，密碼只經標準輸入管道傳遞，不出現在程序參數。

macOS 須在「系統設定 → 隱私權與安全性」允許 YourDesk 的螢幕錄製與輔助使用。請固定使用同一個已簽章 App，避免同時啟動多個舊版。

中央訊號服務僅提供 TLS 1.3 HTTPS／WSS；IP 直連使用 TLS 1.3，以連線密碼 HMAC 綁定當次 TLS exporter 驗證握手。影像與控制使用 WebRTC DTLS。本專案僅提供 Client／遠端顯示，不包含中央 Server 原始碼及執行檔。

## 從原始碼建置

```sh
./buildMac.command        # 清空 dist，只建置 Mac arm64，完成 App 簽章與公證
./buildWin.command        # 清空 dist，只建置 Windows amd64
./pack.command            # 清空 dist，建置與封裝；DMG 簽章、公證
./pack.command --no-build # 保留 dist，封裝既有版本
./runUITest.command        # 本機編譯、固定 Developer ID 簽章後開啟 UI
```

需要 Go 1.24 以上、Python 3.9 以上與 zsh。macOS 使用 Xcode Command Line Tools、Developer ID 及可用的 notarytool Keychain profile，以 `YOURDESK_NOTARY_PROFILE` 指定。Windows 交叉編譯需要對應 MinGW 工具鏈。

詳細內容見[建置與打包](docs/BUILD.md)及[架構說明](docs/ARCHITECTURE.md)。編譯／語法檢查不代表已驗證實機連線、GPU 效能或完整下載安裝流程。

### Windows 硬體加速

Windows 透過共用 Media Foundation／D3D11 後端偵測 NVIDIA、Intel、AMD 等顯示卡的 H.264 能力，不依品牌名稱硬編碼。編碼與解碼分別以探測影格驗證，只有通過才參與協商；不支援或運行失敗時回到 JPEG。新版依協商的 GOP 編碼，未支援相依影格的舊版維持逐張關鍵影格；解碼器必須提供 D3D11 表面才宣告硬體解碼。實際 GPU、編解碼器名稱及失敗 HRESULT 記錄於執行日誌。

此版尚未接入 Windows HEVC，亦非端到端零複製：目前擷取、縮圖輸出及 遠端顯示 顯示仍包含 CPU 記憶體傳輸。已完成 Windows amd64 交叉編譯；Intel／AMD 實機、不同驅動及多 GPU 組態仍待驗證，未宣稱實測 FPS 或延遲改善。

遠端顯示 標題列的 FPS 左側提供編碼狀態圖示，以直向分隔線區隔。滑鼠停留時顯示來源 JPEG／H.264／HEVC 與軟體／硬體編碼，以及接收端軟體／硬體解碼。來源每秒與切換時透過 video-status 控制訊息回報；JPEG 使用當次備援編碼器的狀態，macOS 讀取 VideoToolbox 的 UsingHardwareAcceleratedVideoDecoder 屬性。尚未收到影格、舊版來源未回報或無法取得屬性時顯示等待／未知，避免誤標硬體加速。

### 實機確認與畫質調整

使用者已確認一台 Intel CPU／NVIDIA 顯示卡的 Windows 實體電腦通過 H.264 硬體編碼探測，實際連線至 macOS 遠端顯示 時顯示來源硬體編碼、接收硬體解碼。這不代表 Intel／AMD、所有 NVIDIA 型號或驅動均已驗證。

Windows H.264 與 macOS H.264／HEVC 支援協商 GOP，預設間隔 10 張；GOP 1 用於逐張關鍵影格相容模式。新版明確串流設定優先套用來源 FPS、目標碼率及 GOP；未協商的舊版沿用原畫質控制。品質控制或硬體編解碼失敗時可退回 JPEG。

待機 Client 每分鐘更新中央服務的握手 offer，避免長時間開啟後超過五分鐘有效期限；遠端顯示 可略過舊 offer 等待更新。更新需包含來源 Client；原有時間與 HMAC 驗證保留。

編碼狀態泡泡採兩欄排列：`來源編碼： 硬體 · H.264`、`接收解碼： 硬體`，軟體路徑對應顯示軟體。Windows 啟動器、Client 子程序與 PowerShell 硬體識別查詢共用無主控台啟動設定，避免開啟 YourDesk.exe 時跳出 PowerShell。

HEVC／H.264 來源狀態優先使用 Client 的明確回報；舊 Client 未回報或狀態尚未到達時，依現行協定只允許通過驗證的硬體編碼器產生這兩種影格，顯示「硬體」。JPEG 同時可能使用軟／硬體，未取得來源回報時維持「未知」。

Windows 剪貼簿寫入使用同執行緒建立的 message-only window 作為 owner，關閉剪貼簿後才銷毀視窗；不借用桌面視窗。文字統一 CRLF／LF 轉換，Mac 圖片寫入同時發布 PNG／TIFF，以提升雙向應用程式相容性。RAW 掃描碼依實體鍵映射，啟用按鍵映射時，Mac → Windows 的 Command 轉為 Ctrl，Windows → Mac 的 Ctrl 轉為 Command，左右側保持對應。注入時按來源按鍵追蹤共用的遠端修飾鍵，避免其中一鍵放開就提前釋放遠端鍵；舊 key 協定以來源 platform 識別映射方向。

進階設定的「MacOS/Windows 按鍵映射」位於「顯示使用提示」下方，預設開啟並自動保存。已開啟的 遠端顯示 約每秒讀取設定；切換時會清除待送按鍵並釋放遠端已按住的按鍵。同平台操作不受影響。設定以 `disableKeyMapping` 儲存，舊設定缺少此欄位時預設啟用；跨平台映射需要接收端支援此功能。

## macOS 工具列互動與剪貼簿接收

WebView 回報可見按鈕範圍，原生標題列拖曳層避開這些範圍；按鈕可在視窗未啟用時接受第一次點擊。泡泡由程式控制顯示與關閉，忽略滑鼠事件，避免點擊先被泡泡消耗。

剪貼簿接收先分流檔案讀取、回覆與確認訊息，再按原順序發布其餘剪貼簿內容，避免 Finder 同步要求內容時阻塞接收處理。同步失敗後可重試相同剪貼簿版本，尚未確認的同版檔案快照會重用。通訊格式維持相容；建議兩台 Mac 都更新，才能同時取得傳送端重試與接收端分流修正。Mac 對 Mac 剪貼簿已由使用者實際操作確認正常。

## 遠端顯示 自動配合遠端比例

一般設定新增「調整畫面滿版」，預設關閉，舊設定未提供 `fitWindow` 時同樣關閉。開啟後，遠端顯示 在視窗尺寸穩定約 200 ms 後調整視窗寬高，扣除工具列高度，使內容區配合目前遠端畫面比例；不裁切或拉伸畫面。只改寬或高時以該方向為準，雙向或切換來源尺寸時取目前範圍內可完整容納的比例。一般視窗顯示暫時採等比例縮放，既有縮放模式仍保留，關閉此開關後恢復使用。

全螢幕及切換動畫期間不調整視窗；全螢幕比例與遠端不同時仍可能保留黑邊。功能僅作用於 遠端顯示，不修改遠端解析度、FPS 或碼率設定。設定會自動保存並套用到已開啟的 遠端顯示。
