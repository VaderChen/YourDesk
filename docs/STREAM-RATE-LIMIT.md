# 共用影像傳送流量控制

## 適用範圍

Mac、Windows 等平台共用 Host 傳送層；與 Viewer 作業系統無關。JPEG、H.264、HEVC 都使用同一條限速路徑，包含退回 JPEG 的情況。Viewer 既有碼率設定透過串流協商傳給 Host，不需新增協定。

## 計算方式

Host 依協商的 CBR 目標設定傳送上限；未收到明確目標時使用 12 Mbps。每個編碼批次攜帶設定快照，避免編碼與傳送工作者共用可變設定。

每個影像分片在送出前等待其位元組數對應的傳輸時間，包含應用層影格標頭；不累積閒置期間的額度，因此桌面恢復更新時不會消耗累積額度突發傳送。編碼器本身仍套用原本的碼率目標。

12 Mbps 等於每秒 1,500,000 位元組，工具列以 1024 換算時約為 1.43 MB/s。此上限針對影像應用層資料，不是網卡總流量限制；控制、剪貼簿、網路標頭及重傳不包含在影像預算內。工具列 RX／TX 包含控制與剪貼簿，因此總值可能略高，檔案傳輸時可能明顯更高。網路緩衝及取樣邊界也可能造成短暫波動。

## 延遲與中止

限速只等待影像傳送工作者，不阻塞控制通道。沿用既有有界管線與背壓，保留相依影格順序，不以任意丟棄已編碼影格換取速度。大型影格與低頻寬仍可能增加延遲、降低更新率；這不是自動畫質調整功能。取消工作階段或斷線可中止等待。
