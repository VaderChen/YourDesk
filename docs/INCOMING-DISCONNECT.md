# 本機被連線時停止遠端連線

本機 Host 的 P2P 連線建立後，Tray 顯示「關閉遠端連線」，主介面設定按鈕右側顯示紅色 STOP 圖示；沒有被連線時隱藏。兩者共用停止動作，透過本機私有管線關閉目前被控端的 Peer，保留 Host 程序並恢復待機，不結束主介面，也不關閉本機主動連往其他電腦的遠端顯示。

狀態以 P2P 已建立為準，不以 Host 程序存在、FPS 或完成密碼認證判斷。狀態事件包含工作階段世代，避免上一段連線的延遲斷線事件遮蔽新連線。Tray 約每秒更新；主介面沿用既有狀態輪詢，因此顯示與隱藏可能稍有延遲。

macOS 實驗性未登入服務模式透過安裝位置的固定 helper 與 broker 溝通，僅允許目前主控台使用者查詢或停止。broker 不把配對密碼回傳給 UI；停止動作仍交由服務 Host 關閉 Peer，不停用系統服務。服務副本必須包含此次變更，舊副本需停用後重新啟用以更新。

此功能納入 1.26.0911 build 1012；驗證範圍為平台編譯與語法檢查，未進行額外實機連線測試。
