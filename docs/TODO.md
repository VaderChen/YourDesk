## Windows 服務模式：SYSTEM 的 MCP 權限問題

- [ ] 完成安全修正審查、Windows 實機驗證與部署。
- 優先級：高（權限安全）。保留實機驗收待辦，不以編譯或發布取代驗收。
- 已確認現象：登入前啟動服務使用 SYSTEM 身分，互動終端機回報停用，但 MCP `run_remote_shell` 仍可執行；唯讀診斷 `whoami` 曾回報 `nt authority\system`。
- 原因：MCP 遠端資料入口原本僅以 `os.Geteuid() == 0` 排除 root，未正確排除 Windows SYSTEM／服務帳號。
- 目前進度：本機原始碼已有共用 `useraccess` 檢查，涵蓋互動 Shell、MCP 短指令與檔案入口的能力註冊及請求處理；既有修正隨 build 0058 納入套件；已通過編譯，但尚未完成修正後 Windows 實機驗證，不視為已驗收。
- 驗收：服務模式不得公告或執行受禁的 Shell／檔案指令；一般使用者模式仍正常；帳號查詢失敗一律拒絕；更新服務獨立執行檔並重啟後確認修正生效。
- 不包含：服務模式首張畫面較慢的效能問題，以及以已登入使用者身分提供 Shell 的新代理功能。
