# YourDesk

[繁體中文](../README.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

YourDesk は macOS と Windows に対応するリモートデスクトップアプリです。接続先の管理からコピー＆ペーストまで、使い慣れた操作で別のパソコンを利用できます。

![YourDesk](../images/cap001.png)

## 主な機能

接続終了用のトレイ項目と赤いボタンを追加し、MCP 許可リスト内の IP は Token 不要になりました。macOS のログイン前接続は初期状態で無効の実験機能で、実機未検証です。制限と変更内容は [リリースノート](RELEASE-1.26.0911-build-1012.md) を参照してください。

- **ハードウェアエンコード・デコード**：macOS の H.264／HEVC、Windows の H.264 に対応。両端の機器の能力に応じて自動選択し、利用できない場合は代替方式に切り替えます。実際の処理状態はツールバーで確認できます。
- **クロスプラットフォーム操作**：Mac と Windows 間でキーボード、マウス、一般的なショートカットを使用。
- **簡単な接続管理**：リモート ID で接続し、接続先の保存、グループ分け、並べ替え、インポート／エクスポートが可能。
- **コピー＆ペースト**：テキスト、画像、ファイル、フォルダーに対応。ショートカットや右クリックで貼り付けられ、ファイルとフォルダーは一度に最大 2 GiB。
- **柔軟な表示**：ツールバー中央の最大 4 個の番号付きボタンでリモートモニターを切り替え、ウィンドウに合わせる表示、原寸表示、全画面表示。
- **画面強化**：自動調整、滑らかさ優先、ネットワーク負荷優先を選択し、FPS とビットレートも調整可能。
- **状態表示とカスタマイズ**：FPS、転送速度、ヒント表示、明暗テーマ、4 言語、設定の保存、更新通知。

## 新機能：AI Agent 向け MCP

AI Agent からリモート接続、画面取得、キーボード・マウス操作、切断、接続診断、設定変更ができます。

![「設定 → MCP 設定」で有効化してください。初期状態は無効です](../images/mcp-enable-notice.ja.svg)

IP 許可リストは初期状態で有効、許可先は `127.0.0.1` のみです。有効時はリスト内はトークン不要、リスト外は拒否します。無効時はすべての接続にトークンが必要です。

ローカル接続先は `http://127.0.0.1:12345/mcp`。リモート画面は初期状態で非表示となり、トレイの色と通知で操作中を示します。トレイから表示・非表示を切り替えられます。通常の接続認証と OS 権限が必要です。[MCP ガイド](MCP.md)を参照してください。

## ダウンロードと使い方

[GitHub Releases](https://github.com/VaderChen/YourDesk/releases/latest) から、macOS Apple Silicon 用 DMG、Windows x64 または Windows ARM64 用インストーラーをダウンロードしてください。macOS 版は署名・Apple 公証済みです。

1. 両方のパソコンに YourDesk をインストールして起動します。
2. リモート ID を入力するか、保存した接続先を選びます。
3. 接続パスワードを入力して操作を開始します。

macOS では画面収録とアクセシビリティの許可が必要です。Windows は WebView2 Runtime が必要です。Intel Mac と Linux デスクトップ版は未対応です。接続先で有効にすると IP 直接接続も利用できます。接続は暗号化され、直接通信できるネットワークが必要です。

## 画面強化と補間

送信する画面を縮小し、手元で拡大することで転送負荷を軽減します。利用者の感想では、特に 1440p や 4K など高解像度のリモート画面で効果が大きくなります。機器に応じて FSR または Core ML を選択できます。

実験的な **2× 補間**は Apple Silicon、macOS 13 以降で利用できます。Apple 低遅延補間または RIFE を選択できます。自動モードは対応する macOS 26 以降の Mac で Apple を優先します。画面強化と補間は初期状態では無効です。効果は環境によって異なり、速い動きや小さな文字に乱れが生じる場合があります。

## 日常操作と更新

片方でコピーし、もう片方で貼り付けできます。ファイルの貼り付け進捗はシステムが表示します。リモート画面を閉じるとメイン画面に戻り、メイン画面を閉じるとトレイに常駐します。完全に終了するにはトレイから終了するか、macOS で Cmd+Q を使用します。

「情報」から更新を確認できます。ダウンロード後は赤字で 10 秒カウントダウンし、キャンセルまたは即時更新を選べます。終了後はアプリを自動終了し、更新をインストールして再起動します。自動更新に失敗した場合は案内に従って手動でインストールしてください。

## Windows 装置 ID の更新と Host 重複問題の修正

**Windows の装置 ID 重複による Host 占有問題を修正しました。** 旧版で使用していた CPU の ProcessorId は、別のパソコンでも同じ値になる場合があります。新版は Windows MachineGuid を使用し、無効な場合は SMBIOS UUID を使用します。

> **更新後、Windows の装置 ID（識別番号）が変わります。新しい ID を確認し、他のパソコンに保存した接続先を更新してください。古い ID は使用しないでください。Mac の ID は変わりません。**

接続先の追加・編集とクイック接続では、ID の英数字だけを入力すると、大文字化、`YD-`、4 文字ごとの `-` を自動で適用します。完全な ID の貼り付けや IP アドレスの入力にも対応します。
