## Known issue / 已知問題 / 既知の問題 / 알려진 문제

**繁體中文**：部分電腦可能出現重複 Host 占用問題，導致該電腦無法被連線。目前暫時只能重新啟動電腦後再嘗試連線；此方式不保證恢復。我們正在處理這個問題。

**English**: Some computers may encounter a duplicate Host occupancy issue that prevents incoming remote connections. For now, restart the affected computer and try connecting again; this workaround does not guarantee recovery. We are working on this issue.

**日本語**：一部のパソコンで Host の重複による接続枠の占有が発生し、そのパソコンにリモート接続できなくなる場合があります。現在の暫定対処は、対象のパソコンを再起動してから接続を再試行することです。復旧を保証するものではありません。この問題は現在対応中です。

**한국어**: 일부 컴퓨터에서 중복 Host가 연결을 점유하여 해당 컴퓨터로 원격 연결할 수 없는 문제가 발생할 수 있습니다. 현재 임시 대응은 해당 컴퓨터를 재부팅한 뒤 다시 연결하는 것이며, 복구를 보장하지는 않습니다. 이 문제를 해결 중입니다.

## Changes

- Added background connection analysis with remote version information and concise recommendations.
- **Higher capture FPS on macOS:** continuous desktop capture avoids rebuilding the capture session for every frame. In a local Apple M4 Pro / 1080p H.264 smoke test, throughput increased from 9.38 to 57.19 FPS; configured limits of 20 and 30 FPS achieved 19.81 and 29.65 FPS. These are short local measurements, not guaranteed remote-session FPS or end-to-end latency results.
- **Double Buffer streaming:** capture, encoding and transmission now run as separate stages with two work slots at each handoff, allowing adjacent stages to overlap. The receiver also separates packet reception from decoding with a two-slot buffer. Buffer depth remains bounded to avoid accumulating outdated frames; Double Buffer alone is not a guarantee of lower latency.
- Added Windows GPU desktop capture with a software fallback. Windows performance gains still require real-device validation.
- Added automatic stream configuration options and proportional Remote Display window fitting.
- Added local Host startup checks and a confirmation dialog when an existing Windows Host process can be identified. These safeguards do not fully resolve the known occupancy issue.
- Renamed user-facing Viewer labels to Remote Display; added explanations for reduced FPS and traffic on a still screen.
- Improved warning visibility and cleaned up idle connections used for presence checks.
- After downloading and verifying an update, the app automatically opens the macOS disk image or Windows installer. The download location is labeled clearly; the red “Quit application” button exits the app and its managed remote sessions before installation.

## Packages and validation

macOS Apple Silicon DMG and Windows x64 / ARM64 installers. macOS packages are signed and notarized. Platform builds and syntax checks completed; the duplicate Host issue remains under investigation.
