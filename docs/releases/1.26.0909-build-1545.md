# YourDesk 1.26.0909 build 1545

## Screen enhancement

- Added an experimental Screen Enhancement settings page with FSR 1 (EASU + RCAS) and Core ML backends.
- Bundled QuickSRNet Small 2× and SESR M5 2× for Apple Silicon Macs. Selecting Core ML reveals a model selector, defaulting to QuickSRNet Small. Model availability is checked at startup; failures fall back to FSR 1.
- Reduced transmission width and height to 75% of the original when enhancement is supported by both endpoints.
- Added three strategies: Auto adjustment, Display smoothness priority, and Network load priority. Auto preserves the existing FPS and rate policy; smoothness requests twice the source FPS limit with the configured bitrate budget; network priority retains the FPS limit and halves that budget.
- Added a toolbar indicator with the active strategy, actual backend, source/transmission/display dimensions, bitrate and fallback status.
- Empty unsupported-method groups now display “None”.
- No frame interpolation is included. Actual FPS and bandwidth depend on the hardware, encoder and network.

### When enhancement helps

Current user experience indicates that enhancement benefits become more noticeable at higher remote desktop resolutions, such as 1440p or 4K. Scaling each dimension to 75% leaves 56.25% of the original pixels, a 43.75% reduction. The percentage is constant, but the absolute number of pixels saved increases with resolution: 907,200 per frame at 1080p versus 3,628,800 at 4K.

Actual FPS and bandwidth depend on the selected strategy, encoder, hardware and network bottlenecks; Remote Display upscaling also costs more at larger input sizes. Lower-resolution desktops and dense small text may show more noticeable detail loss.

## Streaming and usability

- Added versioned, composable streaming parameters with capability negotiation, session/revision tracking and effective-setting acknowledgements.
- Retained compatibility with older streaming parameters. Update both endpoints for the new 75% resolution and strategy controls; changing a Core ML model only requires the Remote Display update.
- Closing the Remote Display now brings the main window back to the foreground.

## Downloads

- macOS Apple Silicon: Developer ID-signed and Apple-notarized DMG.
- Windows x64: NSIS installer.
- Windows on ARM (WOA): installer containing native ARM64 application binaries.
- SHA256SUMS: checksums for the three installers.

Windows installers are not Authenticode-signed. Core ML is available only on supported Apple Silicon Macs; Windows uses FSR 1. Windows ARM64 builds have been compiled, but WOA hardware behavior has not been validated on a physical device.

## Validation

Go builds and JavaScript syntax checks completed. Both Core ML model packages compiled successfully. Release packaging validates macOS signatures, notarization tickets and Gatekeeper acceptance. No additional functional regression suite was run.
