本版將檔案與目錄剪貼簿改為先建立快照、公布可貼上清單，再由系統貼上時讀取內容，並取消檔案固定限速。

- 檔案與目錄使用獨立可靠通道，支援子目錄及空目錄；每批最高 2 GiB、64 個最外層項目，目錄合計 4096 筆、64 層。
- Windows 透過虛擬檔案串流支援右鍵貼上；macOS 使用內建唯讀 WebDAV 掛載提供 Finder 檔案路徑。系統預覽要求內容時也可能觸發讀取。
- 保留已開始貼上的快照，不再因失焦、開啟選單或後續截圖而取消既有檔案讀取；不顯示 YourDesk 傳輸進度對話框。
- 移除檔案每片固定等待 8 ms 的節流，依待送緩衝調節，保留鍵鼠與畫面優先。實際速度依網路與磁碟而定。
- 舊 control 剪貼簿通道保留純文字備援；新增 macOS／Windows Command 與 Ctrl 映射開關，預設開啟並保存設定。
- Windows Remote Display 使用自訂標題列，視窗控制鈕位於右側；修正舊標題列閃現、頂端間隙與視窗持續縮小。Windows 選單改用系統原生樣式。
- Tray 左鍵開啟主畫面、右鍵顯示選單；Remote Display 關閉提示、編碼狀態與「低流量」名稱一併整理。
- 更新下載顯示進度；Windows 套件改為 Installer EXE，自動更新優先選取 Installer，仍保留既有 ZIP 的處理能力。
- 建置與打包直接輸出至 dist 下的平台目錄，不再多一層版本號目錄；安裝包檔名保留版本。

更新相容性：

- 快照及右鍵貼上協定需要兩端都更新。
- 已使用新協定的版本，這次加速只需更新檔案來源端；雙向加速則更新兩端。
- 舊版更新器若僅識別 ZIP，請手動下載本版 Windows Installer。安裝前請從 Tray 結束舊版與 Remote Display。

驗證範圍：使用者已確認 Mac 來源至 Windows 的系統貼上流程正常。加速效果、反向 Finder 路徑及其他系統組合尚未完成實機驗證；本次執行編譯、語法與發行封裝檢查，未額外執行功能測試。

附件提供 macOS Apple Silicon DMG、Windows x64 Installer、版本資訊及 SHA-256 清單。macOS 套件經 Developer ID 簽章及 Apple 公證；Windows 套件尚未做 Authenticode 簽章。
