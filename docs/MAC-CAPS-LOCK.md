# Mac 對 Mac 的 Caps Lock 傳遞

原本接收端只同步大寫鎖定狀態，忽略放開事件；傳送端也將每次 Caps Lock 狀態變化直接補成按下／放開。這不足以保留 macOS 辨識按鍵操作所需的實體狀態。

調整後，傳送端保留 Caps Lock 的 stateless 實體按下旗標與放開時機，較舊的事件來源仍補成一次完整按鍵。Mac 接收 Mac 輸入時傳遞 flagsChanged 的鎖定及實體狀態，不先以 IOKit 的鎖定設定取代按鍵；清理按鍵時明確移除實體按住旗標。

輸入來源與大小寫行為交給遠端 macOS 的鍵盤設定處理，不強制改成 Control+Space，不改動使用者輸入來源設定。Windows 傳到 Mac 的既有鎖定同步保持原樣。

此修正須更新兩端的 Mac 程式，並重新建立遠端連線。已做 Client／遠端顯示編譯檢查；尚未完成兩台 Mac 的實機 Caps Lock 切換驗證，不能僅依編譯成功宣稱輸入法切換已修復。
